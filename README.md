# Telegram-бот на базе Google Gemini 3.8 Flash для помощи в учебе

Умный бот для мгновенного решения задач, тестов и объяснения тем с поддержкой фотографий и рукописного текста.

## 🚀 Возможности
- **Распознавание фото**: фотографируйте задачу, тест или конспект — модель распознает рукописный и печатный текст и решает по шагам.
- **Модель Google Gemini 3.8 Flash**: ультра-умная, точная, с поддержкой глубоких рассуждений (thinking).
- **Память диалога**: можно задавать уточняющие вопросы («объясни подробнее пункт 2»).
- **Сброс контекста**: команда `/new` или `/clear`.
- **Работа 24/7 на Render.com**: доступен с телефона без VPN.
